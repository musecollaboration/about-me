# About Me — Блог Разработчика

Персональный сайт-блог на [MkDocs Material](https://squidfunk.github.io/mkdocs-material/), посвящённый обучению и профессиональному росту в веб-разработке.

Содержит дорожную карту изучения бэкенда (FastAPI, Python) и фронтенда (Vue.js, JavaScript), а также информацию об авторе и его авторском курсе.

## Технологии

- [MkDocs](https://www.mkdocs.org/) — генератор статических сайтов
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — тема оформления
- Markdown, YAML, CSS3
- GitHub Actions (CI/CD)

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/musecollaboration/about-me.git
cd about-me

# 2. Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить локальный сервер
mkdocs serve
```

Откройте http://localhost:8000 в браузере.

## Локальная разработка

```bash
# Перезапуск с hot-reload (изменения в docs/ применяются автоматически)
mkdocs serve

# Проверка сборки без ошибок (strict-режим)
mkdocs build --strict

# Сборка в папку site/
mkdocs build
```

Все страницы находятся в папке `docs/`. Каждая `.md`-файл — отдельная страница.


## Сборка и деплой

Деплой автоматизирован через GitHub Actions. При пуше в `main`:

1. Сборка MkDocs + Material
2. Генерация HTML
3. Коммит в `gh-pages`
4. Публикация через GitHub Pages

Ничего настраивать не нужно — всё работает из коробки.

## Конфигурация

Основные настройки в `mkdocs.yml`:

| Параметр | Описание |
|---|---|
| `theme.name` | Тема `material` |
| `theme.font` | Шрифты: Inter (текст), JetBrains Mono (код) |
| `theme.palette` | Тёмная тема по умолчанию (`slate`), светлая по кнопке |
| `theme.features` | Табы, секции, поиск, копирование кода и т.д. |
| `extra_css` | Подключение кастомного CSS |
| `nav` | Структура навигации |
| `extra.social` | Ссылки в футере (GitHub, Stepik) |

### Смена темы по умолчанию

Палитры в `mkdocs.yml` упорядочены: первая — тёмная, вторая — светлая. Чтобы поменять тему по умолчанию, поменяйте их местами.
